# houtaijiekou
用来储存我的后台管理的相关接口
主要是用ssm+springboot+mybatis-plus+vue进行开发
1. 主要用MyBatis-Plus做了基础的增删改查：比如用户信息、数据列表的新增/编辑/删除，还加了简单的条件查询（像按名称、时间筛选）；
2. 后端这边也简单处理了请求参数校验、全局异常捕获；
3. 前端用Vue搭的页面，用到了Element组件库做布局（比如表格、表单），用Pinia存了点全局状态（像用户登录信息），还加了动态路由；最后用ECharts做了个简单的统计图表，把数据可视化出来。
前端用到了动态路由,pinia,element ,echarts等些东西。
